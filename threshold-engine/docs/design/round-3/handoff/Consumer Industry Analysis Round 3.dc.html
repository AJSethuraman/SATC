10 · Glossary
Glossary
What each term means, and how the workbook calculates it. Grouped by the tab the term first appears on.
Tab ▾
Term
What it means
How it is calculated
Summary
Rating
1 to 5: Low, Moderate-Low, Moderate, Moderate-High, High. Called a rating so it is not confused with a measure that is itself a score.
1 plus the number of lines the value is at or past (past only, if a value on a line gets the better rating).
Points
The gap between the bank's latest value and its peer group's.
The bank's latest value minus the peer group's latest value for the same product and measure, in the measure's units. Blank when either is missing.
Signals
Pack line
