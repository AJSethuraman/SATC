Foundations & components

The system behind Invoicer — colors, type, spacing, and the reusable components that build every screen and document. Built on vanilla CSS variables in static/css/style.css, all WCAG AA accessible.

01

Color

A deep navy carries identity; an accessible blue drives every action; cool slate neutrals hold structure and text. Status colors (paid / sent / overdue) come from a tight, AA-safe set. White-on-blue uses #2563eb — passing AA at 5.1:1 — while the lighter #3b82f6 is reserved for hovers, tints, and focus rings.

Spacing, radii & elevation

A 4px base scale keeps rhythm consistent across the UI and the invoice. Radii stay moderate — credible, not toy-like. Shadows are cool-tinted and used sparingly for genuine elevation.
