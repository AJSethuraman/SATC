The confidentiality line earns its place. Most email footers are boilerplate nobody reads. This one does real work — it heads off the most likely way sensitive data reaches you insecurely, which is a client attaching it to a reply. Kept short on purpose.

Install — Outlook (desktop)

Windows & Mac
  1. Open this file in a browser.
  2. Select the signature block above — click just before the mark, then shift-click after the last line.
  3. Copy.
  4. Outlook → File → Options → Mail → Signatures.
  5. New, name it SATC, paste into the edit box.
  6. Set it as default for New messages and Replies/forwards.

Install — Gmail / web

Any browser
  1. Copy the block as above.
  2. Gmail → Settings → See all settings.
  3. Scroll to Signature → Create new.
  4. Paste. Don't retype anything — Gmail will restyle it if you edit inside the block.
  5. Set the defaults below the box for new mail and replies.
Plain-text fallback
Some clients strip HTML entirely. Set this as your plain-text signature so you're never left with a broken block.
