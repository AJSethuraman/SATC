02An extension is more time to file, not more time to pay

Interest and penalties run from the original due date on anything unpaid. Filing the extension protects you from the late-filing charge. It does nothing about the late-payment charge, and the two are separate.

17 fields + 2 repeating lists of 2 + 2 flags. Both conditionals sit inside section 02, so neither drops a numbered section and nothing needs renumbering.

Deliberately not here

  1. No apology, and no reason. Why the extension was needed is a conversation, not a paragraph in a form letter. Whichever side it favours, putting it in writing on a document that goes out hundreds of times is a bad trade.
  2. No fee. The invoice owns it, and an extension notice that also asks for money reads as a bill and gets filed as one.
  3. No signature line. Nothing here needs signing. The extension is already filed.
  4. No new deadline the firm invented. Every date in this letter is either statutory or the materials deadline the firm already publishes.
  5. No "don't worry". An extension is routine and the letter's tone says so by being short. Saying it out loud invites the opposite reading.

For whoever wires the software

  1. PaymentEnclosed and NoPaymentRequired must be derived from one stored value. Two independent booleans can both be false, which would leave section 02 with a warning and no instruction — the worst possible version of this letter.
  2. MaterialsDeadline is keyed by season stage as well as return type. The onboarding letter and the organizer carry the original-season value; this letter carries the extension-season one. Same field name, different setting. A registry that stores one value per return type will print the wrong date here.
  3. OutstandingItems is what is still missing, which means it is derived by subtracting what arrived from the onboarding letter's RequestList. If that subtraction is done by hand it will drift.
  4. Strip the .f class and the .cond markers on the client-facing render.
  5. Name the output: SAT-C Extension Notice — Reyes — 2026.pdf.
