## Why it ended at round 16

Not a cap, not an error — the victory condition. Evidence from
`data/arena.db`, not from the console:

- `matches` row: `max_rounds = 48`, `status = completed`,
  `winner_agent_id = grael`, created 08:22:03.183Z, completed 08:26:58.525Z.
  The 48 was applied.
- Event `seq=807`, round 16, phase `referee`, type **`crown_extracted`**:
  *"Grael Thantos walks out under open sky with the Ember Crown"*, with
  `attunement_rounds: 2` and `crown.status: carried → escaped`.
- Event `seq=817`, type `final_scores`, payload `"ended_reason": "extraction"`.
- `engine.py:803-805` sets `winner_agent_id`, `status = completed` and
  `ended_reason = "extraction"` the moment an escape resolves;
  `engine.py:159-161` breaks the round loop on `_is_terminal()`.

So `--rounds` is a ceiling, and this seed's match was won at round 16. A
forty-eight-round match is the design's *maximum* length, not its expected
one — worth knowing for the PRD's "about a minute a round" live-stream plan,
where the show's length is whatever the crown allows.
