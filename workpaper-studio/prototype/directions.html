Three visual directions

The same slice of the same workpaper, drawn three ways: a credit review's income and debt section with one calculation that cannot run yet and one question from the reviewer. All three show synthetic data.

Recommended: A, the workpaper. The person doing the work and the person checking it both end up reading the finished page, so the screen should be that page. Direction B's side panel is worth borrowing, as something you open when you want to trace a number. Its density suits the setup screens. Direction C is a good way to learn a tool and a slow way to use one every day, so it only earns a place as a first-run walkthrough.
