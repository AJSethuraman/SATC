Every tool shares one shell. Navigation, saving, review and sign-off behave the same everywhere, so a person who knows one tool knows them all.
The middle is the configuration. A question framework reads as questions, a sample reads as a grid, and a reconciliation reads bank against books. Same engine, different shapes.
The brand is the buyer's. Each organization's name and colour carry through, because the tool should feel like theirs, not ours.
